# Folio PDF

Windows 11 向けのローカル PDF ビューアです。PDF の閲覧・ページ整理・抽出／結合・印刷に対応します。Tauri 2、React、PDF.js を使用し、ファイルを外部へ送信しません。

## 起動

[v1.2.0 のリリース](https://github.com/yuma1nu/FolioPDF-Tauri/releases/tag/v1.2.0) から Windows x64 用の `Folio.PDF_1.2.0_x64-setup.exe` をダウンロードして実行してください。インストールされるアプリ名、スタートメニューとショートカットの名前は `Folio PDF` です。WebView2 Runtime が必要です。インストーラーと実行ファイルは未署名です。

公開版のインストーラーの SHA-256 は同じリリースの `SHA256SUMS.txt` で確認できます。ローカルでビルドした場合は `src-tauri/target/release/bundle/nsis/Folio PDF_1.2.0_x64-setup.exe`、インストールせずに試す場合は `src-tauri/target/release/folio-pdf.exe` を使用します。

## 操作

- Ctrl+O、エクスプローラーからのドロップ、関連付け後のダブルクリックで PDF を開きます。追加起動したファイルは既存アプリへ渡します。
- サムネイルやページ番号で移動。Ctrl+F で文書全体を検索します。
- Ctrl+ホイールで 25〜1600% の拡大縮小。Space+ドラッグや中ボタンドラッグで移動します。
- 「ページ整理」で回転・並べ替え・削除・抽出。Ctrl／Shift で複数選択。ドラッグまたは前後移動ボタンで並べ替え、Undo／Redo が使えます。
- Ctrl+S で別名保存。原本と読み込み済み PDF への上書きを拒否し、一時ファイル経由で保存します。
- 「結合」で複数 PDF を指定順にまとめます。タブの未保存編集は含めません。
- 右上の矢印から別ウィンドウへ移動・取り込み。未保存編集、Undo／Redo、検索語、選択、閲覧位置を保持します。受け渡しに失敗した場合は元のタブを保持します。
- Ctrl+P で軽量な印刷プレビューを開きます。「すべてのページ／指定ページ」で対象を選び、`1-3, 5, 8-10` のように入力するか、プレビューをクリックして選択・解除できます。入力とクリック選択は連動します。
- 印刷画面内でプリンターを選び、「ドライバー設定…」から用紙・両面・トレイなどを設定します。設定は今回の印刷画面内だけに保持し、Windows 全体の既定設定は変更しません。「用紙に合わせる／実際のサイズ」も選べます。
- 「選択したページを印刷」を押すと、選択ページだけを印刷品質で準備し、Windows の共通印刷画面を開かずにプリンタードライバーへ送信します。準備・送信中は中止できます。送信完了はスプーラーへの受け渡し完了を意味し、紙への出力完了ではありません。送信済みのジョブはプリンターのキューで確認してください。
- 設定でライト／ダーク／OS の外観、タブ／別ウィンドウの既定動作、セッション復元を変更します。
- 閉じる際の未保存編集は「保存／破棄／キャンセル」から選びます。保存ダイアログをキャンセルした場合は閉じません。

## ファイルとセッション

開いた PDF の元データはメモリー内に保持します。原本の更新・削除・切断をバックグラウンドで検知し、表示と編集を維持したまま通知します。未編集のタブは再読み込みできます。編集中の場合は別名保存してから開き直してください。ネットワーク共有の応答が遅い場合、変更通知も遅れることがあります。

タブ、アクティブな文書、閲覧位置、ウィンドウの位置・サイズ、設定と最近使ったファイルを復元します。同じ PDF を複数のウィンドウから開くと既存のタブへ移動します。試作版の設定形式を自動変換します。壊れた JSON 設定は別ファイルへ退避して初期状態で起動します。

保存済みファイルが復元対象です。未保存編集の異常終了からの復旧、Electron 版の設定の移行には対応しません。設定を含む保存先はアプリ固有の領域で、Electron 版とは分かれています。

## 対象外と制限

- OCR、本文の直接編集、注釈の作成、電子署名検証、フォーム入力・保存、クラウド同期は対象外です。
- 暗号化・署名・権限制限・未対応形式の PDF は閲覧中心です。
- ページ編集・抽出・結合では、しおり・フォーム・注釈・内部リンクを完全には保持できない場合があり、保存前に案内します。
- 印刷プレビューは最大 220×280 ピクセルの小さな画像を表示範囲から描画し、画面外のキャンバスは解放します。印刷ボタンを押すまで全ページの高解像度画像は作りません。実際の印刷では選択ページを最大 150dpi で準備し、大判ページではメモリー上限に合わせて解像度を下げます。プリンター固有の余白、両面、混在用紙サイズなどは実機での確認が必要です。
- 出力先の用紙サイズ・方向はドライバー設定に従います。ページごとの自動用紙切り替えは行いません。PDF 保存などの仮想プリンターでは、ドライバー側の保存先画面が表示される場合があります。
- 大きな PDF では元データと描画キャッシュに相応のメモリーを使います。保存・印刷・ウィンドウ間移動はバイナリ IPC を使い、PDF 処理はワーカーで実行します。
- 自動更新・コード署名は未導入です。OS の既定 PDF アプリは Windows の設定から選びます。

## 開発と検証

Node.js 24 以降、pnpm、Rust stable（MSVC）、Visual Studio の「C++ によるデスクトップ開発」、Windows SDK、WebView2 Runtime が必要です。

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm build:desktop
pnpm dist:win
pnpm test
pnpm test:smoke
pnpm test:print
pnpm check:rust
pnpm test:rust
pnpm test:native
```

`dev:web` は画面の開発サーバーだけを起動します。通常のブラウザーからネイティブ機能は利用できません。`test:smoke` はネイティブ境界を差し替え、実際の画面・PDF.js・ワーカーで PDF の表示、編集、保存、抽出、結合を検証します。

`test:native` はリリース実行ファイルを独立した設定・WebView プロファイルで起動し、追加起動、ウィンドウ間移動、外部変更、セッション復元、印刷用ページを検証します。プリンターの列挙と設定読み込みは実処理を通し、最後の送信だけをテスト内で差し替えます。CDP で PDF 出力し、実プリンターへ送信しません。インストール済みのプリンター（仮想プリンターも可）が必要です。他に Folio PDF が起動していない状態で実行してください。テスト成果物は `test-results/` に保存します。

`test:print` は 60 ページの図面を使い、最初のプレビュー表示、表示範囲だけの描画、入力とクリック選択の連動、範囲の検証、選択ページだけの出力、キャンセルと再実行を検証します。プリンター選択、ドライバー設定の確定・キャンセル、プリンターがない場合の操作も検証します。
