# Folio PDF v1.1.0

印刷画面の表示速度と、印刷ページを選ぶ操作を改善しました。

- 全ページを印刷品質へ変換してから画面を開く方式をやめ、元 PDF とページ構成を渡して印刷画面を先に表示します。
- プレビューは最大 220×280 ピクセルで、表示範囲から順に描画します。画面外のキャンバスは解放します。
- 「すべてのページ／指定ページ」、`1-3, 5, 8-10` 形式の入力、プレビューのクリック選択を追加しました。入力とクリック選択が連動し、選択数を表示します。
- 印刷時に選択ページだけを高解像度で準備します。プレビューの画像品質は実際の印刷品質へ影響しません。
- 範囲外・不正なページ指定、未選択の印刷を防ぎ、準備のキャンセルと再実行に対応します。
- 印刷を開始した時点のページ順・回転・削除を維持し、準備中の古い画像が次の印刷に混ざらないよう検証します。

インストーラーは `Folio PDF_1.1.0_x64-setup.exe` です。ソースとローカル生成物を更新しており、GitHub への公開は別途行います。検証の内容は [VALIDATION.md](../VALIDATION.md) を参照してください。
