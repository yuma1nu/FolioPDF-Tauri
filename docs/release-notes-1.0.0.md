# Folio PDF v1.0.0

試作版で未対応だった、日常利用向けの機能を実装しました。製品名は Folio PDF です。

- Windows の印刷ダイアログと、現在のページ構成を反映した印刷用ウィンドウ。
- 別ウィンドウへの移動・取り込み。未保存編集、Undo／Redo、検索、選択、閲覧位置を保持。
- 複数ウィンドウと位置・サイズの復元、全ウィンドウでの設定と履歴の共有。
- PDF の関連付け候補への登録、コマンドラインの PDF 読み込み、追加起動の既存プロセスへの受け渡し。
- ネイティブのファイルドロップによるパス取得と履歴・復元への対応。
- 外部での原本更新・削除の検知と、未編集タブの再読み込み。
- 未保存編集を閉じる際の「保存／破棄／キャンセル」。
- バイナリ転送による保存・印刷・ウィンドウ間移動、破損した設定ファイルの退避。

Assets の `Folio.PDF_1.0.0_x64-setup.exe` をダウンロードして実行してください。インストール後のアプリ一覧、スタートメニューとショートカットの名前は `Folio PDF` です。WebView2 Runtime が必要です。インストーラーと実行ファイルは未署名です。`SHA256SUMS.txt` にはインストーラーの SHA-256 を掲載しています。

OCR、本文編集、注釈作成、署名検証は対象外です。印刷の物理的な仕上がりはプリンターの設定と機種に依存します。その他の制限は [README](../README.md) を参照してください。
