# Folio PDF Tauri v0.1.0

Windows x64 向け Tauri 2 試作版の初回プレリリースです。React + PDF.js の画面を Windows WebView2 上で動かします。

## インストール

Assets の `Folio.PDF.Tauri_0.1.0_x64-setup.exe` をダウンロードして実行してください。インストーラーと実行ファイルは未署名です。WebView2 Runtime が必要です。未導入の場合はセットアップがダウンロードするため、インターネット接続が必要です。

`SHA256SUMS.txt` にはインストーラーの SHA-256 を掲載しています。

## 主な機能

- 複数タブでの PDF 閲覧、サムネイル、全文検索、倍率変更。
- ページ回転・並べ替え・削除、Undo / Redo、抽出・結合。
- 原本への上書きを防ぐ別名保存。
- ライト／ダーク／OS の外観、最近開いたファイル、タブと閲覧位置の復元。

## 制限

- 単一ウィンドウの試作です。印刷、OS の PDF 関連付け、コマンドラインからのファイルオープン、単一起動制御、外部変更監視は未対応です。
- 暗号化・署名・権限制限のある PDF では編集を制限します。
- ページ編集・抽出・結合では、しおり・フォーム・注釈・内部リンクなどを完全には保持できません。
- 未保存編集の再起動時復元、および Electron 版の履歴移行には対応していません。

機能・制限の詳細は [README](../README.md)、実施した検証は [VALIDATION.md](../VALIDATION.md) を参照してください。
