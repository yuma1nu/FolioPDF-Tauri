# Folio PDF v1.2.0

Windows の共通印刷画面を開かず、プリンタードライバーへ直接送信できるようにしました。

- Folio PDF の印刷画面でプリンターを選べます。最初は Windows の既定プリンターを選択します。
- 「ドライバー設定…」からプリンター固有の用紙・両面・トレイなどを変更できます。今回の印刷画面内だけに保持し、Windows 全体の既定設定は変更しません。
- 「用紙に合わせる／実際のサイズ」を選べます。
- 軽量なプレビュー、指定ページの入力、クリックによるページ選択を引き継いでいます。
- 選択したページを準備し、ドライバー設定を保持したまま Windows のスプーラーへ送信します。送信の中止とエラー後の再実行に対応します。
- プリンターがない場合や設定を読み込めない場合は、理由を表示して送信を無効化します。

送信完了は紙への出力完了を意味しません。送信済みジョブは Windows のプリンターキューで確認してください。仮想プリンターではドライバー側の保存先画面が表示される場合があります。物理プリンターとメーカー固有の設定画面は実機での確認が必要です。

Assets の `Folio.PDF_1.2.0_x64-setup.exe` をダウンロードして実行してください。インストール後のアプリ名は `Folio PDF` です。WebView2 Runtime が必要です。インストーラーと実行ファイルは未署名です。`SHA256SUMS.txt` にインストーラーの SHA-256 を掲載しています。検証内容は [VALIDATION.md](../VALIDATION.md) を参照してください。
